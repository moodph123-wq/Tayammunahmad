# موقع أحمد لوهيا الشخصي — نسخة أولية قابلة للتجربة

## تشغيل الموقع
1. فك ضغط ZIP.
2. افتح `index.html` في متصفح حديث.
3. استخدم زر «إدارة المحتوى» لإضافة وتعديل وحذف الأعمال والمقالات والمشاريع.
4. صدّر نسخة JSON احتياطية من لوحة الإدارة.

## محتويات المشروع
- `index.html`: الصفحة والمكونات.
- `assets/style.css`: التصميم المتجاوب.
- `assets/app.js`: البحث وإدارة المحتوى المحلي.

## ما الذي تتضمنه النسخة؟
- موقع عربي RTL متجاوب.
- معرض أعمال مع تصنيفات.
- مقالات مع بحث ونافذة قراءة.
- قسم مشاريع.
- لوحة محلية لإضافة وتعديل وحذف الأعمال والمقالات والمشاريع.
- إعدادات البريد وروابط التواصل.
- استيراد وتصدير نسخة JSON.

## تنبيه تقني مهم
هذه نسخة واجهة أمامية تجريبية. البيانات تحفظ في `localStorage` داخل المتصفح الحالي فقط، ولا تنتقل تلقائيًا بين الأجهزة، ولا توجد قاعدة بيانات أو تسجيل دخول حقيقي. أي زائر يستطيع فتح لوحة الإدارة إذا وصل إلى هذه النسخة. كما أن التغييرات لا تُنشر تلقائيًا على موقعك العام.

لتحويلها إلى موقع كامل على `tayammun.com` يحتاج المشروع إلى خادم خلفي/API، وقاعدة بيانات، وتسجيل دخول وصلاحيات، وتخزين للصور والملفات، واستضافة وربط النطاق. لا تضع بيانات حساسة في النسخة الحالية.
